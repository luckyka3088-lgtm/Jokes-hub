😂 Joke Hub

Joke Hub is a simple, responsive joke website where users can enjoy jokes in English, Hindi, and Gujarati. Jokes are organized into categories such as Funny, Coding, and School.

✨ Features

- 😂 Random jokes
- 🌐 Three languages:
  - English
  - हिंदी (Hindi)
  - ગુજરાતી (Gujarati)
- 🏷️ Multiple categories:
  - Funny
  - Coding
  - School
- 🔄 Get a new joke with the Next button
- 📋 Copy jokes with one click
- 📤 Share jokes
- 📱 Responsive and mobile-friendly design
- 🎨 Simple and clean interface
- ⚡ Font Awesome icons

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome

🚀 Getting Started

1. Clone the repository

git clone https://github.com/your-username/joke-hub.git

2. Open the project

Go to the project directory:

cd joke-hub

3. Run the website

Open "index.html" in your browser.

For the best development experience, you can use VS Code with Live Server.

🎯 How It Works

Joke Hub loads jokes from separate JavaScript files for each language.

Language
   │
   ├── English
   ├── Hindi
   └── Gujarati
        │
        ▼
    Category
        │
        ├── Funny
        ├── Coding
        └── School
        │
        ▼
    Random Joke

The user can change the language or category and use the Next button to display another joke.
